Super Store Sales Dashboard – Power BI
📊 Project Overview
The Super Store Sales Dashboard is an interactive Power BI dashboard designed to analyze sales performance, profit, quantity, payment methods, product categories, and shipping modes.

The dashboard provides meaningful insights into business performance through interactive visualizations, KPI cards, and regional filters, helping users understand sales trends and make data-driven decisions.

🖥️ Dashboard Preview
The dashboard includes:

Regional filters (Central, East, South, West).
Key Performance Indicators (KPIs).
Monthly sales and profit trends.
Payment mode analysis.
State-wise sales and profit distribution.
Category and sub-category sales analysis.
Shipping mode analysis.

🎛️ Interactive Features
Regional Filtering: Filter dashboard data by Central, East, South, and West.
Dynamic Visualizations: Charts update based on selected filters.
KPI Monitoring: Quickly track total sales, quantity, and profit.
Comparative Analysis: Compare monthly sales and profit across years.
